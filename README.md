## 🛠️ Tech Stack

This project is built using:

- **ReactJS (Vite)** - Fast, modern frontend framework
- **Tailwind CSS** - Modern utility-first CSS styling
- **@splinetool/react-spline** - Interactive 3D Spline scene
- **AOS (Animate On Scroll)** - Scroll-triggered animations
- **Framer Motion** - Fluid interactive UI animations
- **Lucide Icons** - Clean icon system
- **Supabase** - Backend database for projects, certificates, and comments
- **SweetAlert2** - Toast notifications and alert dialogs
- **React Helmet Async** - SEO meta tag management

## 🚀 Getting Started

### Prerequisites

- Node.js `>= 18.x`
- npm or yarn

### 1. Clone & Install

```bash
git clone https://github.com/nadhifshoeemagoldist-wq/Portofolio_V5.git
cd Portofolio_V5
npm install
```

> If you encounter peer dependency issues: `npm install --legacy-peer-deps`

### 2. Environment Variables

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your-supabase-project-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

> **Note:** The application includes safe fallback defaults, so the UI and animations will run smoothly even before connecting your Supabase project.

### 3. Run Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## ☁️ Deploy to Vercel

This repository is pre-configured and ready to deploy seamlessly on [Vercel](https://vercel.com):

1. Push your repository to GitHub.
2. Go to **Vercel Dashboard** → **Add New Project** → Import your repository.
3. Configure the Project Settings:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install --legacy-peer-deps`
4. Add your **Environment Variables** in Vercel Project Settings:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. Click **Deploy**!

> `vercel.json` is included in the project to handle client-side Single Page Application (SPA) routing and rewrites automatically.

## 🗄️ Supabase Database Setup (Optional)

If you wish to host your own projects, certificates, and comment system via Supabase:

1. Create a project at [supabase.com](https://supabase.com).
2. Go to **SQL Editor** and run the following tables setup:

```sql
-- Tables setup
CREATE TABLE public.projects (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  "Title" text,
  "Description" text,
  "Img" text,
  "Link" text,
  "Github" text,
  "Features" jsonb,
  "TechStack" jsonb,
  is_published boolean DEFAULT true,
  order_index int DEFAULT 0,
  created_at timestamptz DEFAULT now()
);

CREATE TABLE public.certificates (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  "Img" text,
  created_at timestamptz DEFAULT now()
);

CREATE TABLE public.portfolio_comments (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  content text NOT NULL,
  user_name text NOT NULL,
  profile_image text,
  is_pinned boolean DEFAULT false,
  created_at timestamptz DEFAULT now()
);

CREATE TABLE public.profiles (
  id uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  username text UNIQUE NOT NULL,
  role text NOT NULL CHECK (role IN ('admin', 'user')),
  created_at timestamptz DEFAULT now()
);

-- Row Level Security (RLS)
ALTER TABLE public.projects ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.certificates ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.portfolio_comments ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;

CREATE POLICY "public read projects" ON public.projects FOR SELECT USING (true);
CREATE POLICY "public read certificates" ON public.certificates FOR SELECT USING (true);
CREATE POLICY "public read comments" ON public.portfolio_comments FOR SELECT USING (true);
CREATE POLICY "public insert comment" ON public.portfolio_comments FOR INSERT WITH CHECK (is_pinned = false);
```
